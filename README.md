# Google PAA Scraper
Automated Google People Also Ask (PAA) scraper built with Python, Playwright, and Excel export support. SEO research tool that extracts Google People Also Ask questions and saves them to Excel.

## 🚀 Features

- Extracts People Also Ask (PAA) questions from Google search results
- Handles dynamic loading and page scrolling
- CAPTCHA detection with automatic pause/resume support
- Resume scraping from previous runs (no duplicate work)
- Saves results continuously to prevent data loss
- Exports structured data to Excel

## 🛠 Tech Stack

- Python
- Playwright
- Pandas
- OpenPyXL
- Win10Toast (notifications)
